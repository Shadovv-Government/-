# Capibara: командное решение кейса

Здесь собраны материалы хакатона и распределение работы между четырьмя компьютерами. Начните с [КОМАНДА.md](КОМАНДА.md): там задачи, границы ответственности, требования к решению и готовые сообщения для Codex или Claude Code.

## Начало работы

Каждый участник клонирует этот репозиторий и создаёт **свою** ветку. Если репозиторий закрыт, для клонирования и отправки веток нужен доступ к нему.

```bash
git clone https://github.com/Shadovv-Government/-.git capibara
cd capibara
```

Затем используйте команду для своего компьютера:

```bash
# Компьютер 2 — качество данных и проверки
git switch -c team/quality

# Компьютер 3 — SQL-ответы
git switch -c team/analytics

# Компьютер 4 — дашборд и защита
git switch -c team/presentation
```

Запустите только одну команду `git switch -c` — соответствующую вашей роли. После этого откройте папку `capibara` в Codex или Claude Code и передайте ему текст для вашего компьютера из [КОМАНДА.md](КОМАНДА.md). Компьютер 1 отвечает за модель и интеграцию.

## Локальная база

При запущенном Docker и доступе к интернету:

```bash
cd project
bash scripts/setup.sh
```

Скрипт организаторов скачивает исходные CSV и загружает их в локальный PostgreSQL. Подробнее об окружении и устранении ошибок — в [project/README.md](project/README.md). Данные из `project/data/` не коммитятся. `--reset` удаляет локальный volume базы проекта — используйте его только когда это действительно нужно.

## Как передать результат

Работайте в своей папке, указанной в плане. Когда работа готова, сохраните её в своей ветке и отправьте на GitHub:

```bash
git add project
git commit -m "Describe your changes"
git push -u origin HEAD
```

Сообщите команде название ветки и откройте pull request в `main`, если у вас есть доступ. Не отправляйте секреты или исходные CSV. Если модель или её контракт ещё не готовы, начинайте независимую часть своей задачи и сообщайте о необходимых изменениях компьютеру 1.
