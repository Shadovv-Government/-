# Финансовая сверка

После загрузки raw и сборки core, из `project/`:

```bash
docker compose exec -T postgres psql -X -v ON_ERROR_STOP=1 -U hack -d marketplace < computer-3/quality/financial_reconciliation.sql > computer-3/quality/financial-result.txt 2>&1
```

Скрипт сравнивает число строк, число непустых сумм и точные суммы цены и доставки по каждому заказу, продавцу и исходной категории с разбивкой по статусу; платежи отдельно сравниваются по заказу. Полное соединение показывает отсутствующие группы с обеих сторон; пустая категория и непроданные заказы не теряются из-за обязательного перевода. Он не считает цену равной платежу и не смешивает отдельные факты. Максимум 50 примеров расхождений каждого типа выводятся перед ошибкой; ненулевой код процесса означает ошибку выполнения или несовпадение. Сверка не доказывает равенство каждой позиции внутри группы: для детальных полей и ключей нужна отдельная проверка компьютера 2.

При отсутствии расхождений выводится PASS. Сверьте также итог `core_delivered` с 13221498.11 товарной выручки и 2202965.54 доставки из контракта; эти значения относятся к исходному снимку. После обновления данных не считайте старые ориентиры обязательными. Вывод файла сохраните и передайте команде вместе с версией данных и БД.
