Проверка SQL четвёртой роли: берутся цены позиций доставленных заказов без доставки, как и для общего итога. `LEFT JOIN` сохраняет товары без категории или перевода, а категория без перевода выводится под исходным названием. Сумма совпадает с вопросом 1 для этого снимка, хотя вопрос 1 ограничен периодом 2016-09 — 2018-08, а вопрос 5 считает весь снимок: после обновления данных эти периоды нужно проверять заново. Запрос группирует по отображаемому названию категории; если у разных исходных категорий появится одинаковый перевод или название `UNKNOWN`, группы могут объединиться. Для будущих данных безопаснее группировать по исходному ключу, а отображаемое название хранить отдельно; это замечание передано здесь без изменения чужого SQL.
